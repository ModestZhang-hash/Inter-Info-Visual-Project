## 三种编码各自呈现什么

**散点图矩阵**复用 `app/shared/pair_scatter.mjs`。三行三列对应 `makespan_s`、`energy_j`、`mean_latency_s`。对角单元用文字写出轴名、单位和最小化方向，不调用散点图组件。非对角单元每次重绘都新建 SVG。反向单元与正向单元共用同一组二维标签，键为 `makespan_s|energy_j`、`makespan_s|mean_latency_s`、`energy_j|mean_latency_s`。它适合逐对查看 M–E、M–L、E–L。小单元沿用组件原有的 600×390 viewBox，再用 CSS 缩小；这一步没有修改 `pair_scatter.mjs`。

**平行坐标**把 M（秒）、E（焦耳）、L（秒）画成三条垂直轴，都标明最小化。每条完整且配置可见的运行是一条折线，颜色和形状字符来自完整 `model.configs` 上的 `stableConfigIndex()`。折线位置可以按当前坐标域归一化，归一化只用于绘制。悬停文字保留存储中的原始 M/E/L。它适合同时看三个目标的高低，轴上的刷选用来挑出落在某个原始值区间内的运行。

**简洁 3D** 使用无依赖 SVG 的固定斜投影，没有旋转控件，也没有引入 Three.js。画面横向主要对应 M，向上主要对应 E，斜向对应 L。投影参数固定为 `VIEW3D`：`depth = 0.55`，`angle = π/6`，先按当前坐标域把三个原始值归一化到绘图位置。金色虚线圈表示 `model.labels.full` 中的三维非支配。它适合看三个目标放在同一投影里时点的相对位置；固定视角会有遮挡，不能靠转动把点分开。

## 共享状态与选择

三种视图读取同一批已校验记录。点、折线的身份是 `run_id`，不是数组下标。配置颜色和形状槽位使用完整配置集合，不使用筛选后的配置列表。

选择、可见性和坐标只调用已有的 `selectRuns()`、`setVisibleConfigs()` 和 `setAxisRange()`。

- 筛选只替换 `visible_policy_config_ids`。它不改 `axis_ranges`、`pareto_reference_run_ids`，也不重算二维或三维标签。
- 「显示全部」把全部配置重新标为可见。它不选中这些运行。
- 「清除选择」调用 `selectRuns([])`。选中计数、高亮和详情会清空。点和折线仍留在图上，因为它们表示运行本身。
- 平行坐标的轴刷选范围只留在该模块内部。松手后，在当前可见且完整的运行里取落在范围内的 `run_id` 并调用 `selectRuns()`。多轴刷选取交集。它不调用 `setVisibleConfigs()` 或 `setAxisRange()`。
- 3D 点击一个点时，若其他可见点与它的投影距离不超过 `OVERLAP_PX = 14`（同一 viewBox 坐标系），则一次选中该位置上的全部 `run_id`。

失败运行不画成矩阵点、平行坐标折线或 3D 点。支配标签来自 `readBundle()` 对完整候选集合的分类。演示数据中，F（`3a-demo-run-f`）在 M–E 上被 G（`3a-demo-run-g`）支配，三维仍非支配；详情保留未舍入值，其中包括 `E=5.0925 J`。

## 3D 遮挡检查

在演示 bundle 的默认坐标域上，用 `projectRun()` 计算七个点的 viewBox 坐标。最近的一对是 C 与 D，距离约 44（测量值 43.8）。没有任何一对小于或等于 14，因此这七个演示点没有触发“同一投影位置”的合并选择。Node 测试断言每个演示点的 coincident 列表只包含它自己的 `run_id`。浏览器中这七个点也能分开看出，D、E、F、G 带有三维非支配标记。

默认演示页面只有一个实例和七个完整点。下面这些情况由测试覆盖：

- `dominance handles exact ties, an equal axis, tolerance, and instance isolation`：完全相等的向量互不支配；容差内仍可判为支配；不同 `instance_id` 不能放进同一次分类。
- `3D dominance can coexist with a tied, non-dominated 2D projection`：三维上的支配可以和二维投影上的相等、非支配同时存在。
- `failed run is not classified and stale Python check is rejected` 与 `a failed run is omitted from every matrix cell`：失败运行不进入分类，也不画进矩阵。
- `witness contains deterministic full metrics and tolerance relations`：多个 witness，以及 `equivalent_within_tolerance` 关系。
- `shared filters do not rewrite the reference IDs or axis ranges` 里的 `changeInstance("another", ...)`：新实例的运行列表不包含原先选中的 `3a-demo-run-f` 时，`selected_run_ids` 变为 `[]`。
- `one session highlights the same run across 3A and 3B views`：隐藏到一个配置后，轴域和 F 的二维标签保持不变。
- `the shared page loads the demo bundle once for every view`：页面只请求一次演示 bundle，来源文字含 `fixture_only`，点击 F 后详情出现 `3a-demo-run-g` 和 “strictly better”，3D 高亮同一 `run_id`，清除选择后为 None。

分类使用未舍入存储值。演示点 A 的 `energy_j` 在测试中等于 `6.965`。显示舍入不进入 `classify()`。

导入另一份 bundle 时，`app/app.mjs` 的 `loadBundle()` 会新建 session。新的 `selected_run_ids` 初始为空，四个视图会重新挂载。本次没有第二份 bundle 的浏览器导入记录，也没有测试断言旧图形已被移除。
